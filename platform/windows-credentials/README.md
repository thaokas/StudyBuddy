# Windows 加密凭据服务

实现 DSH 原生 `CredentialProvider` 接口，设置界面和模型适配器继续使用原有凭据 API。服务支持凭据引用、环境变量回退，以及原生凭据记录的读取、修改、删除与更新通知。

存储格式为包含版本、保护方式和密文的 JSON envelope，使用 Windows DPAPI `CurrentUser`。明文仅在内存与隐藏 PowerShell 子进程的标准输入/输出中传递，不写入命令参数或临时文件。损坏文件、解密失败和不支持的平台均返回错误，不回退为明文存储。解析复用 DSH 的安全凭据解析器。

写入在原生跨进程文件锁内重新读取最新文档，再使用原子替换保存密文。`lockWaitMs` 默认 120000，可通过插件配置调整，供异步记录刷新期间的并发写入等待。退出时等待已开始的写入结束。测试使用合成凭据，不读取实际 Key。

依赖已构建的 `source/deepseek-harness` 工作区包；当前实现用于 Windows 开发环境。密文文件应与项目数据一起备份，但复制到另一 Windows 用户或机器后不能保证解密。
