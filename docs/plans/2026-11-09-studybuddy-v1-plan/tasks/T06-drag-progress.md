# T06：拖拽、冲突与进度

> 任务卡只写要求；状态以 [STATUS](../STATUS.md) 为准。开工前先读 [AGENT.md](../AGENT.md)。

- 预计：1 个会话
- 依赖：T05
- 波次：W4
- 状态：见 [STATUS](../STATUS.md) 的 T06 行

## 目标

把"安排—执行—记录"变成直接操作。

## 所有权（只能改这些路径）

- `plugins/study/host/modules/tasks.mjs`（接力）
- `plugins/study/client/pages/workbench.js`（接力）
- `plugins/study/tests/progress/**`

## 交付

- 单块拖拽、跨日移动（只动选中块）。
- 重叠即时提示 + 显式保留；冲突不静默。
- 状态机：未开始 / 进行中 / 部分完成 / 完成 / 取消。
- "待确认"独立标记；数量或文字反馈。
- 并发版本失效提示与重提交。

## 验收

- 拖拽不改任务身份与历史记录。
- 冲突需确认后才保存。
- 未勾选不显示"未学习"。
- 取消不进入完成率。
- 重复点击不重复写。

## 不做

- 整天重排、计划修订。

## 开工前

1. 读 [AGENT.md](../AGENT.md)，确认工程约定与完成标准。
2. 在 [STATUS](../STATUS.md) 确认依赖 T05 均为 DONE；不满足就停下并在 STATUS 写 BLOCKED。
3. 只改"所有权"里的路径；需要共享文件时按 AGENT.md 串行处理。
4. 先写测试或证据脚本，再改实现。

## 完成后

1. 跑测试，记录命令与真实结果（失败也要写）。
2. 把 STATUS 的 T06 行改为 DONE / REVIEW / BLOCKED，填证据与已知限制。
3. 不修改其他任务的状态，不顺手重构无关代码。
