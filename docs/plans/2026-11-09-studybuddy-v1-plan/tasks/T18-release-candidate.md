# T18：发布候选包与运行说明

> 任务卡只写要求；状态以 [STATUS](../STATUS.md) 为准。开工前先读 [AGENT.md](../AGENT.md)。

- 预计：0.5 个会话
- 依赖：T07、T10–T17
- 波次：W7
- 状态：见 [STATUS](../STATUS.md) 的 T18 行

## 目标

交付一个能运行的候选，不承诺安装器。

## 所有权（只能改这些路径）

- `release/v1/**`

## 交付

- 版本锁定清单（DSH 提交、插件版本、schema 版本）。
- 启动脚本/快捷方式。
- 数据位置与冷备份说明。
- 已支持/未提供清单；许可与来源。
- 候选 ZIP 与校验值。

## 验收

- 干净目录解压可启动（本机环境）。
- 无 Key 可本地操作。
- 不连接上游更新源。
- 清单与实际一致。

## 不做

- 安装器、签名、自动更新、对外发布。

## 开工前

1. 读 [AGENT.md](../AGENT.md)，确认工程约定与完成标准。
2. 在 [STATUS](../STATUS.md) 确认依赖 T07、T10–T17 均为 DONE；不满足就停下并在 STATUS 写 BLOCKED。
3. 只改"所有权"里的路径；需要共享文件时按 AGENT.md 串行处理。
4. 先写测试或证据脚本，再改实现。

## 完成后

1. 跑测试，记录命令与真实结果（失败也要写）。
2. 把 STATUS 的 T18 行改为 DONE / REVIEW / BLOCKED，填证据与已知限制。
3. 不修改其他任务的状态，不顺手重构无关代码。
