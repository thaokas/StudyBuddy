# T19：全场景验收与回归

> 任务卡只写要求；状态以 [STATUS](../STATUS.md) 为准。开工前先读 [AGENT.md](../AGENT.md)。

- 预计：1 个会话
- 依赖：T18
- 波次：W8
- 状态：见 [STATUS](../STATUS.md) 的 T19 行

## 目标

用 14 个设计场景验收，产出证据与结论。

## 所有权（只能改这些路径）

- `tests/acceptance/**`
- STATUS 结论行

## 交付

- 逐场景证据（脚本/截图/日志）。
- 失败项修复或登记。
- 回归脚本（冷备份恢复、无 Key、重启）。
- 已知限制清单。

## 验收

- 14 场景全部有结论（通过/未覆盖+原因）。
- 本地功能无 Key 可用。
- 数据迁移与冷备份恢复通过。
- 不把未测平台写成已支持。

## 不做

- 新增功能。

## 开工前

1. 读 [AGENT.md](../AGENT.md)，确认工程约定与完成标准。
2. 在 [STATUS](../STATUS.md) 确认依赖 T18 均为 DONE；不满足就停下并在 STATUS 写 BLOCKED。
3. 只改"所有权"里的路径；需要共享文件时按 AGENT.md 串行处理。
4. 先写测试或证据脚本，再改实现。

## 完成后

1. 跑测试，记录命令与真实结果（失败也要写）。
2. 把 STATUS 的 T19 行改为 DONE / REVIEW / BLOCKED，填证据与已知限制。
3. 不修改其他任务的状态，不顺手重构无关代码。
