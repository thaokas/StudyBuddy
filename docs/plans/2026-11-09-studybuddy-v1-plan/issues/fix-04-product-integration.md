# 修复组 4：产品接入

> 新会话先读本说明，再只读并执行其中一张任务卡。不要一次修多张卡。

## 这一组解决什么

把已经可信的业务事实接到学生的实际使用方式上：首次能用对话建档，记忆按目标和会话工作，拖拽能改同日时段，换书有替代关系，计划能滚动细化。

## 任务卡与顺序

1. [SB-11 首次引导接入真实对话和默认备考会话](tasks/11-onboarding-conversation.md) —— 依赖 SB-01、SB-05。
2. [SB-14 记忆目标/会话作用域、相关注入与纠错抑制](tasks/14-memory-scope-and-correction.md) —— 依赖 SB-05。
3. [SB-15 同日拖拽到起始分钟](tasks/15-same-day-drag.md) —— 依赖 SB-01；可与 SB-11 并行（不同文件）。
4. [SB-16 换书/换任务建立明确替代关系](tasks/16-replacement-relation.md) —— 依赖 SB-01；可与 SB-15 串行，避免同时改 `tasks.mjs`。
5. [SB-18 未来 7 天滚动细化与估算校准](tasks/18-rolling-refinement.md) —— 依赖 SB-01、SB-09；建议最后做。

建议顺序：**SB-11 → SB-14 → SB-15 → SB-16 → SB-18**。  
SB-11 和 SB-14 都涉及目标/会话上下文，建议串行；SB-15/SB-16 都改 `tasks.mjs`，不要并行。

## 完成这一组的标志

- 首次进入可以选“和助手聊”，打开/复用默认备考会话；表单仍可快捷使用。
- 目标 A/B 的记忆、会话和注入上下文不互相污染；纠正旧记忆后旧句不能被重建。
- 同日拖拽能改变开始时间，保持块 ID/任务 ID，冲突有提示。
- 换书创建新任务并保留旧任务完成记录，不把旧书页码题号复制到新书。
- 计划能保存阶段目标 + 未来 7 天详细 + 更远工作量；每日细化有入口，估算可校准。

## 不要做

- 不做 Creator 沙箱、自动记忆提取、安装器/自动更新。
- 不做公开信息联网入库、原始会话导出、跨日补发提醒。
- 不在本组新增第二套目标/记忆/计划存储。
