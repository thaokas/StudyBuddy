# E01：实现资料导入、公开检索与证据片段

大任务：E / Agent 工具  
直接前置：C02  
状态：TODO

## 目标与输入

复用 DSH 附件/读取/搜索能力，向规划和答疑提供可信度明确的材料引用。阅读总览/执行规则/依赖表、C02 服务、B02/B03、设计第 4.1 节和当前 DSH 工具文档。

## 边界

独占 study/agent/materials。索引由 C02 持久化；复用既有解析器，必要补依赖交集成人。无授权平台登录、付费课程抓取、完整视频解析和通用 OCR 平台不在范围内。

## 实施步骤

1. 接入文字、链接、本地文本/PDF、目录截图与既有计划；按当前模型/工具能力识别可读、部分可读、无法读取及需用户补充。
2. 公开信息检索保留来源 URL、查询时间、适用年份和原文片段；年份未知不得作为当年确定要求。自述水平仅标自述。
3. 将目录/课程识别为资料条目和位置引用，允许缺页码/题号的粗略任务依据，不凭空补足细节。
4. 按请求返回预算内的相关片段，不默认发送整份文件；处理引用失效、重复导入、超限文件和解析失败。
5. 将材料当不可信数据，阻断其中的“忽略规则、泄露密钥、直接改计划/安装代码”等指令，外链/文件访问沿用明确权限。

## 验收

- 文本/PDF、截图能力不足、未知年份、冲突来源和损坏附件都有 fixture 和准确状态。
- 公开要求能追溯原文与日期，个人课表与网络信息不混淆；对无法解析的内容不假装已读。
- 提取结果通过 C02 服务保存，重复导入幂等；恶意材料不产生授权或业务副作用。
- E02/E03 获得片段与引用接口，D02 可显示进度/失败；网络测试默认可模拟，真实检索证据单独注明。
