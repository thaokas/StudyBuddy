# E02：实现对话规划工具与提案确认流程

大任务：E / Agent 工具  
直接前置：C02、C04  
状态：TODO

## 目标与输入

用现有 DSH Agent 协商同一份计划，工具负责调用权威服务。阅读总览/执行规则/依赖表、B02/B03、C02/C04 交付和设计计划/授权边界。

## 文件边界

独占 study/agent/planning。计划算法提案可由模型生成，但校验/提交由 C04；不建立第二套 Agent、计划 DB 或工具私有事实库。注册项/提示配置入口交集成人。

## 实施步骤

1. 注册目标/资料/最新计划读取、草案编辑、提案预检/差异、确认提交及撤销工具；身份/作用域/期望版本来自可信运行上下文，不任模型自报绕过。
2. 提供规划上下文：阶段/月周目标、当前周/近期 7 天、固定/可调课程、时间预算、来源缺口、学生要求和估算说明。
3. 多轮请求作用同一草案，只追问显著影响安排的信息；无页码/题号时保留标记，学习/练习/订正/休息纳入容量解释。
4. 对超负荷给风险和替代，用户知情坚持时允许试行；正式确认及自动微调各使用对应授权，材料/记忆不能授权。
5. 版本过期返回可操作冲突，重新读取后重提案；超时/重试复用请求身份，保存成功前不宣称计划已更新。

## 验收

- fake model 可演示首次协商、多轮修改、确认、试行、换书和容量不足；模型非法字段不能写库。
- UI 拖拽后 Agent 读取最新安排；旧提案被拒绝/重算，不能覆盖新版本。
- 工具输出区分提案与已提交事实，附变更原因/来源/未安排量，撤销保留后续学习记录。
- 有工具契约和对话 fixture 测试；F04 可在既定授权范围复用，不绕过 C04。
