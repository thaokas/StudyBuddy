## 目标与输入

从任务进入答疑能获得相关背景，新会话继续备考不依赖无限增长的单一聊天。阅读总览/执行规则/依赖表、B02/B03、E01/E02，以及 D04 上下文协议。

## 范围

独占 study/agent/tutoring。复用 DSH 对话、附件、历史查询和工具；memory 接口按契约可选注入，F01/F02 未完成时降级为空召回，真实效果在 I02 验证。不新增知识掌握度系统。

## 实施步骤

1. 通过可信目标/任务 ID 获取最新学科、资料位置、完成条件和相关片段，带引用组装预算内上下文；不从旧聊天复制正式计划。
2. 支持备考主对话与专题会话关联同一目标；自由聊天可不带任务，切换目标/删除关联立即隔离旧上下文。
3. 按需读取 DSH 历史与小量相关记忆，区分用户原话、模型回答、短期状态和观察；不把一次问题推断为永久能力不足。
4. 处理任务归档、附件失效、资料不足、模型能力不支持和 token 超限；说明限制且不伪造已阅读章节/推导证据。
5. 为前台答疑与后台复盘提供优先级/取消配合，避免后台占住同一草案；限制无关资料和隐私片段外发。

## 验收

- 两个会话对同一任务读取同一最新事实；无任务聊天不串入其他目标内容。
- 材料引用可追溯；超预算裁剪可测，不把 Agent 回答当学生事实。
- fake model/历史/记忆覆盖上下文去除、更新、归档、失败与预算；DSH 原有聊天功能保留。
- I01 可验证任务进入答疑，I02 可验证跨会话记忆；未接真实记忆部分明确标注。
