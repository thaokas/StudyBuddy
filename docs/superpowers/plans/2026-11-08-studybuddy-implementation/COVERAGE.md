## 3. 必须在相应能力启用前验证的未知项

- DSH 版本由 A01 固定，候选记忆兼容性由 A03 验证；A03 不阻塞 B01/R01，不用宽泛 peerDependencies 代替实测。
- 插件服务、学习页、导航/会话扩展点：A02，不把独立 SDK UI 当默认后路。
- 原始消息/压缩触发、scope、删除/修订、中文召回：A03，生产适配 F01/F02。
- 受限隔离载体与 Creator 持久化/恢复：A04，可提前排风险，失败阻塞 G/S4 而非 S0—S3；变更安全边界必须交用户决定。
- Windows 通知、凭据保护和写入冻结：A02 探针，H01/H02/H03 正式验证。
- 签名、系统要求、安装体积、更新校验与回滚：H04/I04，未知不写已支持。
- 旧 StudyBuddy 源码/数据格式：A01 记录可获取情况；无证据不承诺自动迁移。

## 4. 默认值与禁止的范围漂移

Windows 首发、精细规划未来 7 天、21:30 复盘、单学生且一个激活目标、小工具限界面/记录类是可调整默认值，不是用户逐项确认的硬要求。实现应支持合理配置，产品范围调整需用户确认。

不增加题库/课程平台、能力诊断/知识图谱、社交/云同步、自有模型服务、全天候云 Agent、插件市场、向量服务/图数据库或惩罚性打卡。分阶段延期已显式列在 RELEASES 中，不代表从 S4 删除功能。不能以 MVP 名义启用不可删除记忆、无限权限小工具或不可靠升级；S0—S3 明确使用停机冷备份，S4 才开放经验证的一致快照/自动更新。
