## 实施步骤

1. 提供最小目标/日期/时间预算表单及手动任务、时间块创建/编辑入口，支持学科、材料文字位置、完成条件和估算；调用 C02/C03，输入不完整可保存且明确标记。
2. 将真实目标/资料元数据、今日/周任务、时间块、拖拽、冲突提示和进度快捷操作接到 D03；将 C05 组件接到真实 H01 生命周期/通知。
3. 按能力隐藏 C04 正式计划/撤销、E03 任务上下文答疑、C06 成果和记忆/Creator/跟进入口。自由聊天继续用原生 DSH；不得向用户展示假数据或 mock 成功。
4. 测试手动创建 → 安排 → 拖拽 → 部分完成/文字反馈 → 计时 → 重启继续；并发/重复点击不重复记，未勾选不推断未学习，睡眠/退出不虚计时。
5. 使用 R01 最小打包流程生成当前提交候选，回归 S0。验证无 Key/断网本地功能可用；AI 能力按现有配置状态准确提示。
6. 演练 S0 → S1：退出全部进程、默认无凭据冷备份、初始化/迁移并重启，再用匹配旧程序+快照回退。记录 S1 新 schema，禁止旧程序直接写新库；自动更新仍关闭。
