# H01：实现桌面生命周期、通知与后台状态适配

大任务：H / 桌面与数据保障  
直接前置：A02、B03  
状态：TODO

## 目标与输入

通过 platform 插件和最薄桌面桥接，准确表达应用运行状态。阅读总览/执行规则/依赖表、A02 接口图、B01/B02/B03。操作系统能力若必须经桌面主进程接入，只做薄桥，业务策略保留插件内。

## 范围

独占 platform/lifecycle。核心 Electron/Host 桥改动交集成人协调；不另造调度器，不保证关机/完全退出后继续执行。不预设关闭窗口等于后台驻留，需明确配置和提示。

## 实施步骤

1. 映射窗口关闭、最小化、后台驻留、显式退出、睡眠/唤醒、网络变化与启动恢复的真实事件，提供统一状态服务。
2. 实现 OS 通知桥和操作回传，沿用 F03 提醒身份，权限拒绝/点击过期/应用未就绪时安全降级到应用内记录。
3. 向计时/跟进/复盘广播少量已定义生命周期事件；恢复只触发重查，不在桥层补发历史业务动作。
4. 提供退出前说明、后台状态提示和有界的写入收尾/取消钩子；不能为了等模型无限阻止退出。
5. 为 H03 登记最小写入屏障参与/释放接口及 DSH 持久化接入位置，记录已验证能力和不能冻结的写入源。S1 必须验证计时/退出/通知生命周期；在线一致快照缺口转交 H03，在补齐前禁用该能力，不阻塞采用停机冷备份的 S1。

## 验收

- 关闭窗口、退出和睡眠含义明确，实际运行与界面声明一致。
- 通知动作幂等回传且不泄露敏感内容；系统拒绝通知不影响本地任务操作。
- Windows 上有真实生命周期/通知冒烟；fake events 覆盖重复唤醒、断网和退出超时。
- C05 真实生命周期接入可用，F03/F04/H03 有统一桥及版本化扩展约定，核心补丁可追踪；冻结能力有证据或明确写出对 H03 的阻断，不将未实现能力误报成功。
