## 目标与输入

学生使用自己的模型服务，Key 不进入聊天、普通文件/日志或默认导出。阅读总览/执行规则/依赖表、A02 模型入口、B02/B03、H01 与固定 DSH 适配器实现。

## 边界

独占 platform/credentials 及其配置/连接组件；D02/D05 负责嵌入。模型调用仍经 DSH，不能另建第二套模型客户端；必要凭据引用解析通过薄桥接，原值不暴露给生成物。

## 实施步骤

1. 继承 R01 已验证的模型适配器、原生配置及最小安全凭据方案，补齐学习界面的设置/诊断，不重新造一条模型链路；记录问答/工具/附件能力矩阵。已有原生配置须有兼容路径，其他 OpenAI-compatible 服务按检查结果开放，不宣传全部兼容。
2. 使用 OS 保护能力存储凭据并持久化引用，验证 Windows 用户上下文下读取、更新、删除和失效；不可用时明确失败，不退回明文 Key。
3. 实现连接检查、错误分类/重试和取消：Key 缺失/无效、URL 错误、TLS/网络、超时、余额/限额及能力不足。
4. 脱敏日志/错误/工具结果，解释模型/搜索会发送相关上下文；默认不启用 StudyBuddy 遥测或未经配置的付费服务。
5. 提供无 Key/离线状态与本地功能可用性协议，备份清单默认排除凭据，恢复后允许重新配置。

## 验收

- 真正 OS 凭据保护与 DSH 调用集成有证据；自动化测试用假密钥，不记录真实 Key。
- 检查默认配置、日志、聊天、生成工具可见数据和导出清单均无 Key。
- 失败不会自动切换未经授权服务；无 Key 时计划查看、编辑、计时可继续。
- D02/D05 可接组件与状态，I01/H04 能复用能力矩阵/运行配置。
