# G01：实现受限小工具执行宿主与权限桥

大任务：G / Creator 插件  
直接前置：A04、B03  
状态：TODO

## 目标与输入

将 A04 验证方案产品化，使默认个人工具不是任意本机代码。阅读总览/执行规则/依赖表、A04 威胁模型/攻击测试、B01 source-map、B02/B03。

## 边界

独占 creator/runtime。运行宿主本身是可信 DSH 插件，生成物在隔离环境运行；宿主不等于把生成包加载进 Host。流程/生成 UI 归 G02，正式计划写入仍归 study。

## 实施步骤

1. 落实 A04 载体的安全配置，禁用 Node、任意文件/网络、父页面/Host 访问和外部导航，隔离预览与启用实例；不靠静态扫描声称安全。
2. 建立按实例/版本/来源校验的消息桥，严格校验请求 schema、能力和作用域，拒绝伪造/重放及跨工具访问，不向生成物传凭据/原始敏感会话。
3. 提供最小能力：读取获准今日/本周任务与摘要、工具私有记录、提交变更提案；正式变更由公共业务服务检查版本和授权。
4. 实现命名空间存储、生命周期、停用即撤权、超时/资源异常隔离和宿主错误降级；工具不得获得插件安装/核心修改能力。
5. 提供 G02 使用的包验证/预览/激活/卸载接口、备份参与者，以及正常/恶意工具测试套件。

## 验收

- 攻击样例无法读写任意本机文件、发任意网络请求、获取 Key、越权读其他目标或直接改 DB。
- 桥接权限来自可信授权，不来自生成代码/记忆/模型文字；停用后在途调用也被拒绝或安全结束。
- 一个工具崩溃不损坏 DSH 或 study；私有记录与权限在重启后可验证。
- 有真实载体下的边界测试证据，不只通过 mock 或代码扫描；失败不得降级为无限权限。
