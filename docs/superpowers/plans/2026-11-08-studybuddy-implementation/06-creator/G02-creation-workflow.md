# G02：实现个人工具创建、持久化与版本恢复

大任务：G / Creator 插件  
直接前置：G01  
状态：TODO

## 目标与输入

用户说“为我制作一个小工具”后，能明确了解行为/数据、预览、启用、修改、停用和恢复。阅读总览/执行规则/依赖表、A04 上游工作流、G01、B02/B03。

## 文件边界

独占 creator/workflow 及其插件 UI；通过 D01 注册点接入对话/个人工具页，公共注册交集成人。复用 DSH Creator/管理生命周期，不另建通用开发平台。不把生成包作为原生 Host 插件默认安装。

## 实施步骤

1. 实现需求澄清与已有功能复用判断，展示具体行为和最少数据需求；用户选择生成后才调用模型，取消/失败状态和费用可见。
2. 生成受 G01 约束的版本化包/清单，验证结构后在隔离预览运行；权限扩大或正式计划变更须重新走可信确认。
3. 实现用户启用、源文件/包/版本持久化、重启加载、继续修改、停用和上一可用版本恢复；新版本失败不覆盖当前可用版。
4. 私有记录沿命名空间存储，读业务摘要/提交提案走桥；不让恢复旧版本绕过当前权限。
5. 提供图表/打卡/复习清单等少量 fixture，测试不支持需求的解释；高级原生插件若保留入口，明确本机代码权限并与默认小工具区隔。

## 验收

- 至少一个统计工具从描述到预览、启用、重启、修改失败、恢复、停用完整走通。
- 未确认不能启用/扩大权限，重复点击不重复生成启用记录；源文件/版本均可备份。
- 请求无限文件/网络能力时明确拒绝受限通路，不偷偷切到原生插件。
- 有工作流/组件/运行集成测试及 D01/I02/H03 接入说明。
