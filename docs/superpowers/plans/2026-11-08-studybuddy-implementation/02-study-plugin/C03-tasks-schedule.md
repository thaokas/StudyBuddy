# C03：实现任务、执行进度与时间块命令

大任务：C / study 插件  
直接前置：C01  
状态：TODO

## 目标与边界

提供 UI、Agent 与工具共用的任务/日程服务。阅读总览/执行规则/依赖表、B02/B03/C01。独占 study/tasks 与 study/schedule；不做整日自动重排、模型规划或工作台 UI。

## 实施步骤

1. 实现任务稳定 ID、学科/资料位置/完成条件/工作量/依赖和未开始/进行中/部分完成/完成/取消状态；核实标记独立，数量或文字反馈不强制虚假百分比。
2. 实现时间块与任务分离、一任务多块、固定课/休息不计学习完成；支持跨天查询、局部拖拽、显式未安排剩余工作及暂定块。
3. 对单块移动/拆分和进度记录使用统一版本/请求身份；保存执行事实、历史和窄事件。即时检测重叠/预算/前置关系，风险保留须显式授权并保持警示。
4. 记录实际已完成量；待确认先保留假设，随后确认已完成时清理对应暂定重复块，但不删真实执行记录。
5. 支持换教材时的新任务/替代关联与历史保留，不根据书名臆测章节等价；跨模块操作使用 C01 事务和审计接口。

## 验收

- 拖拽/跨日不改变任务身份和已有完成记录；同一任务拆块不会重复累计完成量。
- 未勾选只能触发待确认，不自动判为未学习；取消与完成明确区分。
- 冲突可被用户显式保留，但不展示成合理的可同时完成安排；默认移动不连带重排整日。
- 覆盖重复点击、过期版本、部分完成、跨日/时区、固定课程、换书及暂定清理；D03/F03/C04 可调用同一服务。
