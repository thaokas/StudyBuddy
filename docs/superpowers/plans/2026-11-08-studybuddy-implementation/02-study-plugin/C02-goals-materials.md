# C02：实现备考目标、资料索引与来源记录

大任务：C / study 插件  
直接前置：C01  
状态：TODO

## 目标与输入

存储用户目标、可用时间、固定约束与已有教材/课程，为导入、规划和答疑提供统一索引。阅读总览/执行规则/依赖表、B02 契约、C01 交付。使用 B03 真实命令。

## 边界

独占 study/goals、study/materials。解析/搜索流水线归 E01，任务和换书后的任务关系归 C03/C04，首次引导 UI 归 D02。迁移请求交 C01，注册项交集成人。

## 实施步骤

1. 实现学生档案、多个目标/一个激活目标、考试适用年/期限、每日时间预算和偏好/固定事项的业务接口。
2. 实现教材、课程、练习册、目录和资源位置索引；记录版本、来源链接/本地引用、查询日、适用年、读取/核实状态。
3. 区分用户自述、用户提供课表和公开检索证据；年份未知、章节缺失及估算必须可显式标记，禁止自动补齐伪造位置。
4. 支持资料更新、归档和更换关联，保留旧索引与已有执行记录引用；不可因删除一个文件而级联删掉学习历史。
5. 校验路径/附件访问范围，提供需要时读取片段的引用接口，不默认把整套文件发送模型。

## 验收

- 不完整目标也可保存；缺信息的状态明确，后续可补，不强制长表单。
- 同名不同版本书籍、未知适用年份、不可解析资料有无歧义表示。
- 切换激活目标不串读任务/资料；资源失效不会抹去历史。
- 有来源、更新、归档、重复请求、非法引用/越权目标的单元/契约测试；E01/D02 可按接口接入。
