# C05：实现本地番茄钟及中断确认组件

大任务：C / study 插件  
直接前置：C03  
状态：TODO

## 目标与边界

不调用模型也能可靠计时；睡眠/退出后不把离线时间记为学习。阅读总览/执行规则/依赖表、B02/B03/C03。独占 study/timer 及其插件 UI 组件；D03 只负责挂载，H01 提供桌面事件桥。

## 实施步骤

1. 实现学习/休息时长设置、开始/暂停/继续/提前结束及可选任务关联，采用可测试的本地时钟状态机；时间显示不依赖模型或逐秒持久化。
2. 保存足够的状态、周期与执行记录，处理单实例活动计时和重复操作；计时结束只写计时事实，不自动完成任务或推断掌握度。
3. 接入 B02 生命周期/通知协议，先用 B03 mock；睡眠、进程异常/重启、时钟跳变标记中断，要求用户确认有效时长。
4. 提供可嵌入工作台的计时组件与确认面板；普通跟进可获知当前专注态，但不能读取不必要的聊天信息。
5. 覆盖后台延迟、跨日、重复结束、取消、暂停恢复及关联任务被归档的情况。

## 验收

- fake clock 精确可测，无 API Key/断网时功能完整。
- 睡眠一小时或应用关闭期间不会自动增加一小时学习量；中断确认有原始时间和修正依据。
- 计时结束通知幂等，记录不重复；学习/休息分开统计，计时不改变任务完成状态。
- D03 获得组件 API，F03 获得专注状态协议；R02 在 S1 就必须验证真实桌面睡眠/退出和中断，I01/I03 做完整组合回归，不把基本计时可靠性拖到完整首版。
