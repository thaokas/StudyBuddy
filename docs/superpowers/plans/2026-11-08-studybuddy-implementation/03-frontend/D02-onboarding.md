## 目标与输入

用少量配置和自然对话进入学习，不用长表单阻断。阅读总览/执行规则/依赖表、D01 接入协议、B02/B03；使用契约 mock 开发，真实 C02/E01/E02/H02 由 I01 集成。

## 边界

独占 study/ui/onboarding。模型凭据组件由 H02 提供，计划生成由 E02，资料解析由 E01。本任务只显示状态并调用接口，不解析 PDF、不在 UI 私建计划、不修改 DSH 核心路由。

## 实施步骤

1. 实现模型连接入口、数据发送说明和“暂不配置，先看本地功能”路径；失败允许修正/重试。
2. 用对话配合短卡片收集目标、期限、时间预算、已有资料/课程；允许缺省、暂停和下次继续，固定课程/可调课程/参考资料表达清楚。
3. 支持文字、链接、本地附件导入入口，展示读取/核实/适用年份与失败原因；不假装扫描件或视频已成功解析。
4. 展示同一份协商草案、来源/假设、时间容量与风险，提供修改、确认及知情试行；确认前不得展示为正式计划。
5. 提供已保存/待保存/冲突状态、重复点击防护和可访问的错误提示，注册需求交集成人。

## 验收

- 只填少量信息即可保存并进入；重启恢复未完成引导，不重复建目标/计划。
- 缺 Key、超时、资料解析失败、年份不明、超负荷试行都有 mock 组件测试。
- 未确认草案与正式计划视觉/行为明确区分，所有写入走契约服务。
- 提供真实集成所需服务清单和截图；mock 完成不代表 I01 已通过。
