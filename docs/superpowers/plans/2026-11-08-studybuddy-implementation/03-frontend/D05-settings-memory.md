## 目标与输入

让学生可查看/修正个性化记忆、控制跟进授权，而不是只能请求 Agent。阅读总览/执行规则/依赖表、D01、B02/B03；先使用 mock，I02 接 F01/F02，I01 接 H02 和跟进设置。

## 边界

独占 memory/ui、platform/ui/settings。凭据输入/连接检查组件由 H02 提供，本任务负责嵌入；Creator 工作流 UI 由 G02 提供。本任务不直接访问 JSONL、记忆库、钥匙串或生成包。

## 实施步骤

1. 展示记忆内容、来源、时间、作用域、明确/短期/待确认类型、有效期和修订；支持修改、忘记、纠正及操作结果。
2. 清楚解释“删除记忆”与“删除原始对话”不同；展示删除抑制的可理解状态，不承诺对话已被删除。
3. 实现提醒、静默时间、互动语气、晚间时间/自动微调授权、后台成本/取消入口和激活目标设置。
4. 嵌入模型配置入口，提供隐私/数据发送说明；提供备份/导出/恢复以及个人工具管理的路由接入点，不复制其他任务界面。
5. 测试空态、权限/版本冲突、加载/失败、已删除项刷新不再出现、过期状态和键盘操作。

## 验收

- 纠正/删除仅在服务确认后显示成功，失败不掩盖；来源和有效期可见。
- 日常微调授权可关闭，默认值可配置；不把偏好/记忆内容当作新增权限。
- 组件测试不需真实 Key；界面状态受同一契约约束，I02 能验证删除后的实际召回。
- 提供 F/H/G 服务和路由接入清单，核心前端改动交 D01 协调。
