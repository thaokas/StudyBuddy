# D04：实现 DSH 对话与学习任务的交互联动

大任务：D / 前端与交互  
直接前置：D01  
状态：TODO

## 目标与输入

保留 DSH 原生聊天，同时让用户知道当前对话关联的目标、任务和资料。阅读总览/执行规则/依赖表、D01、B02/B03。E03 尚未完成时使用其契约 mock，I01 验证真实链路。

## 范围

独占 study/ui/chat-context，核心前端接入由 D01/集成人处理。服务端上下文组装归 E03，规划归 E02，原有消息/附件/工具运行继续由 DSH 负责。

## 实施步骤

1. 实现任务卡“就此提问”与上下文标签，显示关联目标/任务/资料引用并允许移除，避免自由聊天误带其他任务。
2. 提供持续备考对话与另开专题会话的入口/返回路径；会话关联按稳定 ID 保存，而非把整份计划写入页面状态。
3. 展示 Agent 工具带来的计划/进度变更结果和差异，跳回工作台定位任务；等待、失败、取消和版本冲突准确显示。
4. 前台发消息时配合后台任务优先级协议，允许取消后台调用；显示必要的调用/数据发送状态，不将 API Key 或内部敏感日志写入消息。
5. 与 DSH 历史、附件和工具结果界面兼容，提供任务已归档/资料失效/目标切换的降级处理。

## 验收

- 从工作台进入答疑可见且可移除上下文；自由聊天不被强制绑定任务。
- 新专题会话仍使用相同目标事实，界面不维护另一份聊天计划。
- 使用 mock 覆盖跳转、移除上下文、失败/取消、过期版本和目标切换，保留原生聊天能力。
- 有 E03/I01 接入清单；本任务不能以 mock 消息冒充真实工具执行。
