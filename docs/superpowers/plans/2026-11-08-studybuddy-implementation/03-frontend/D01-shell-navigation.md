# D01：改造 DSH 前端宿主与学习导航

大任务：D / 前端与交互  
直接前置：B03  
状态：TODO

## 目标与输入

让 DSH 本身呈现学习工作台体验，而不是另开一个独立应用。阅读总览/执行规则/依赖表、A02 扩展图、B01 source-map、B02 契约与 B03 测试命令。

## 文件边界

本任务集中维护 DSH 核心前端布局、导航、路由和插件 UI 接入槽。D02—D05 只做插件 UI，不自行改相同核心文件。业务能力不放进壳；Host/Agent 循环不在本任务范围。

## 实施步骤

1. S1 先实现今日/周安排、资料元数据和原生对话入口，保留会话/附件/工具结果；为后续计划、记忆/设置、个人工具定义可选导航注册，不要求提前做齐页面。
2. 提供学习插件页面/组件注册、加载、失效提示和上下文联动接口；核心只传 ID/事件与服务代理，不持有第二份业务数据库。
3. 实现工作台与对话的可切换/并置布局，启动恢复上次目标/页面；首次使用可引导但不阻断本地查看。
4. 为 D02—D05、C05/C06、G02 提供按能力注册的挂载点/路由，S1 只启用已交付页面。缺插件时隐藏入口，不把未来 mock/占位页混进发布；用当前 mock 验证加载失败和版本不符隔离。
5. 明确键盘操作、焦点/对话返回位置、窄窗口、基础无障碍和离线/后台状态展示规则；登记每项核心前端补丁理由。

## 验收

- DSH 原有对话可正常工作，学习插件能加载、卸载/失效而不拖垮整个应用。
- 导航、工作台和对话共享激活目标；业务写入仅经过插件服务。
- 有页面注册示例、组件/导航测试和实际 DSH 冒烟证据。
- D02—D05 可以不改核心公共文件独立开发；上游补丁清单可维护。
