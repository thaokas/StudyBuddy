## 目标与输入

在晚间复盘/会话压缩后批量整理新增证据，避免重复费用和删除后立即重建。阅读总览/执行规则/依赖表、A03、B02/B03、F01；使用已确认的 DSH 历史/压缩接口。

## 范围

独占 memory/extraction。不替代候选召回/存储，不改 DSH 压缩主逻辑，不强制第二把 Key。F04 调用已定义可选维护钩子，本任务实现其生产处理。

## 实施步骤

1. 统一晚间与压缩触发的持久化消息位置/批次身份，领取批次后只处理新增用户证据；重复触发和重启重试不重复落记忆。
2. 使用当前模型、受控上下文预算及来源引用提取三类记忆；带已有相关记忆用于修订去重，禁止把模型回复、计划/题目目录当学生事实。
3. 结合 F01 墓碑与来源/规范化候选检查，阻止旧对话在删除后立即重建；新的用户显式“记住”需走明确的新授权，不能悄悄取消墓碑。
4. 为模型失败/取消、部分成功、删除并发、目标切换和备份冻结设计事务/重试；仅成功处理的范围推进游标。
5. 提供费用/状态、取消与前台优先级，模型不可用时保留待处理；禁止后台任务并发竞争同一草案或影响前台可用性。

## 验收

- 同一段消息的晚间+压缩重复触发只产生一份有效处理结果；模型请求重试/费用的不可避免边界有说明。
- 删除后再整理旧对话不恢复该项；用户纠正优先，短期状态不永久化。
- fake model 覆盖误提取、重复、取消、部分写入、墓碑并发、重启；无 Key 时只待处理不报成功。
- D05 可看到状态/成本并取消，I02 可在真实会话验证整个链路。
