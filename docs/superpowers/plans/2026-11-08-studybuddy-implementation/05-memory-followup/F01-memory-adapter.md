# F01：实现候选记忆插件的生产适配

大任务：F / 记忆与主动跟进  
直接前置：A03、B03  
状态：TODO

## 目标与输入

在已验证候选上提供 StudyBuddy 记忆语义，不重建通用记忆基础设施。阅读总览/执行规则/依赖表、设计第 7 节、A03 兼容矩阵、B01/B02/B03。

## 边界

独占 memory/adapter。尽量配置与薄补丁，新增依赖/插件入口交集成人。提取流水线归 F02，管理 UI 归 D05；原始会话归 DSH，业务计划/完成量归 study。

## 实施步骤

1. 映射学生长期、目标相关、会话临时作用域和独立 profile；绑定单学生多目标语义，不向用户暴露工作区路径概念。
2. 实现带来源/时间的明确表达、短期状态、待确认观察及有效期；较新纠正替代旧结论，明确偏好优先于推测。
3. 提供查看、编辑、纠正、忘记、按相关性/预算召回及历史关系接口；显式记住/修改/忘掉通过同一服务立即处理。
4. 持久化删除墓碑/抑制元数据并提供 F02 检查接口；删除与缓存失效原子一致，备份参与者覆盖候选存储及适配元数据。
5. 做跨会话/重启/目标隔离/中文检索回归，保留候选上游原存储格式，不另启向量或第二个完整系统。

## 验收

- 删除/纠正后即时召回使用新状态，重启后仍成立；旧业务事实不被复制成记忆权威。
- 长期偏好与目标状态正确隔离，短期到期不再当现状使用，来源可查看。
- 有候选适配契约测试和实际 DSH 加载冒烟；补丁范围可追踪。
- F02 获得墓碑/来源/召回接口，D05 获得管理服务，H03 获得冻结/刷新/恢复能力。
