# I02：集成跨会话记忆与个人工具完整流程

大任务：I / 集成与验收  
直接前置：D05、F02、G02  
状态：TODO

## 目标与输入

证明记忆和 Creator 不是孤立 demo，而是 DSH 内可持续使用的能力。阅读总览/执行规则/依赖表、D05/F01/F02/G01/G02 交付、B03 和 A03/A04 原始验证结果。

## 边界

负责跨插件/界面测试、真实接线和证据；修复回原模块所有者，注册/根文件交集成人。本任务可与 I01 并行，使用不同临时数据根，不依赖 I01 的未合并状态。

## 实施步骤

1. 在 DSH 会话明确表达偏好/今日疲惫/一道题的问题，执行显式和批量记忆处理，跨会话与重启验证相关召回、作用域、有效期和来源。
2. 在 D05 纠正/忘记一条记忆，触发压缩与晚间同源批次，验证游标去重、旧对话不立即重建；对话本身仍存在且 UI 解释准确。
3. 从自然语言创建统计工具，检查数据/行为说明、生成确认、隔离预览、启用、重启持久化、修改失败、版本恢复与停用。
4. 用恶意工具尝试跨命名空间、直接写计划、获取 Key/文件/网络/Host，检查受控接口与重新授权，不能靠 UI 隐藏按钮宣称安全。
5. 验证前台对话与后台提取取消/失败互不损坏，原生高级插件入口若存在，权限说明和默认工具通路明确分离。

## 验收

- 至少两个 DSH 会话和一次真实重启；用户纠正覆盖旧观察，短期状态到期不永久使用。
- 删除抑制在重复触发和重新整理旧消息后仍成立，显式重新记住的行为可解释。
- 生成工具完整生命周期和攻击回归在实际隔离载体通过，停用/恢复不获得额外权限。
- 交付自动化/桌面操作脚本、真实结果、残余风险和未执行项；不能用 mock 作为隔离或持久化证据。
