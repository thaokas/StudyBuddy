## 目标与输入

## 边界

负责跨模块接线/端到端测试与验证证据，不接管模块实现。生产缺陷回原所有者修复；核心注册/锁文件交集成人。集成必须保留 DSH 主体，不用测试专用独立业务应用绕开。

## 实施步骤

1. 核对实际插件注册、契约版本、路由和凭据组件，移除生产路径中的 mock/测试 fixture，保留可注入的测试适配器。
2. 测试提供目标/课程/教材 → 缺失信息标记 → 多轮协商 → 知情试行或正式确认 → 今日/周安排。
3. 拖拽后立即询问 Agent，确认读取最新事实；从任务答疑、计时、部分完成/文字反馈、提醒快捷回应都落同一业务源。
4. 推进 fake clock 到晚间，验证只移动剩余量、未核实暂定、容量不足保留未安排工作、摘要与撤销；重启后次日继续。
5. 验证无 Key/断网仍可本地勾选/拖拽/计时，AI 显示待恢复；增加至少一个经过授权的实际基线模型冒烟，或明确该项未执行/阻塞。

## 验收

- 自动化测试运行真实业务服务/DB/DSH 插件生命周期，不以 UI mock 通过代替真实集成。
- 目标、资料、任务身份、版本和执行记录可从数据库/服务结果交叉核对；没有另一份聊天计划。
- 至少覆盖未勾选但实际完成、部分完成且明日无空闲、换书留历史及重排遇手动修改。
- 交付场景脚本、命令/结果、必要截图/脱敏日志和缺陷清单；关键失败不能标 DONE。
