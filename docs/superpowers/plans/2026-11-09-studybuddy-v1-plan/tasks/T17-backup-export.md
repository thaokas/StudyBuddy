# T17：冷备份与数据导出

> 任务卡只写要求；状态以 [STATUS](../STATUS.md) 为准。开工前先读 [AGENT.md](../AGENT.md)。

- 预计：0.5 个会话
- 依赖：T05、T08
- 波次：W4
- 状态：见 [STATUS](../STATUS.md) 的 T17 行

## 目标

给学生一条能照做的备份与恢复路径。

## 所有权（只能改这些路径）

- `scripts/backup-studybuddy.mjs`
- `plugins/study/host/modules/export.mjs`
- `docs/backup.md`

## 交付

- 脚本：检查进程 → 复制数据根 → 写清单与校验。
- 应用内"导出学习数据 JSON"（目标/资料/任务/计划/进度/成果/记忆，排除凭据）。
- 恢复步骤与演练记录。

## 验收

- 关闭应用后备份可恢复且数据一致。
- 导出不含凭据。
- 恢复后任务/计划/成果可交叉核对。
- 文档步骤实际执行过。

## 不做

- 热备份、自动更新、云同步。

## 开工前

1. 读 [AGENT.md](../AGENT.md)，确认工程约定与完成标准。
2. 在 [STATUS](../STATUS.md) 确认依赖 T05、T08 均为 DONE；不满足就停下并在 STATUS 写 BLOCKED。
3. 只改"所有权"里的路径；需要共享文件时按 AGENT.md 串行处理。
4. 先写测试或证据脚本，再改实现。

## 完成后

1. 跑测试，记录命令与真实结果（失败也要写）。
2. 把 STATUS 的 T17 行改为 DONE / REVIEW / BLOCKED，填证据与已知限制。
3. 不修改其他任务的状态，不顺手重构无关代码。
