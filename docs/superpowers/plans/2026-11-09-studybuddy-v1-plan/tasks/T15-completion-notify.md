# T15：回复完成通知

> 任务卡只写要求；状态以 [STATUS](../STATUS.md) 为准。开工前先读 [AGENT.md](../AGENT.md)。

- 预计：0.5 个会话
- 依赖：T02
- 波次：W3
- 状态：见 [STATUS](../STATUS.md) 的 T15 行

## 目标

助手回复结束时提醒一次，系统通知不可用时有页内兜底。

## 所有权（只能改这些路径）

- `plugins/study/client/notify.js`
- `plugins/study/tests/notify/**`

## 交付

- 订阅会话事件识别 turn 结束。
- `Notification` 请求权限与降级。
- 页内提示条。
- 同会话去重、多会话合并、点击聚焦并定位。
- 开关设置。

## 验收

- 完成后只提示 1 次。
- 无权限/不支持时页内提示仍出现。
- 同时完成 3 个会话合并为 1 条。
- 刷新后不重复。

## 不做

- 应用关闭后的通知、托盘常驻、任务到点提醒（T12）。

## 开工前

1. 读 [AGENT.md](../AGENT.md)，确认工程约定与完成标准。
2. 在 [STATUS](../STATUS.md) 确认依赖 T02 均为 DONE；不满足就停下并在 STATUS 写 BLOCKED。
3. 只改"所有权"里的路径；需要共享文件时按 AGENT.md 串行处理。
4. 先写测试或证据脚本，再改实现。

## 完成后

1. 跑测试，记录命令与真实结果（失败也要写）。
2. 把 STATUS 的 T15 行改为 DONE / REVIEW / BLOCKED，填证据与已知限制。
3. 不修改其他任务的状态，不顺手重构无关代码。
